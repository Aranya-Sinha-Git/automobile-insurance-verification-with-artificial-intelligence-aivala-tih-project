# Repository Workflow

This repository is mirrored to the private GitHub repository:

https://github.com/Aranya-Sinha-Git/automobile-insurance-verification-with-artificial-intelligence-aivala-tih-project

After every completed change:

1. Review the diff and confirm that local secrets, databases, model weights, and runtime bundles remain excluded.
2. Run the checks appropriate to the change.
3. Commit the completed change with a concise message.
4. Push the commit to the `main` branch of the `origin` remote.
5. Confirm that the push succeeded and report the commit hash.

Whenever you claim a change was committed, always include the exact commit ID
(full SHA or abbreviated hash) in the user-facing response. Do not say a change
was committed without reporting that ID.

Do not push unfinished work, failing changes, or changes to any other repository.
